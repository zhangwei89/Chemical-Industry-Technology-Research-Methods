# 引用规范与参考文献库

## 一、文内引用格式

采用 GB/T 7714-2015 顺序编码制：

- 单篇：`方法[1]`
- 多篇连续：`已有研究[2-5]`
- 多篇不连续：`对比研究[3,7,9]`
- 引用作者观点：`张三等[10]认为 ...`
- 共引：`如 XX[1]、YY[2]所述`

## 二、文末条目格式

### 期刊论文（J）
```
[序号] 主要责任者. 题名[J]. 刊名, 出版年, 卷(期): 起页-止页.
```
例：`[1] 王小明, 李四. 化工过程强化研究进展[J]. 化工进展, 2023, 42(5): 2100-2115.`

### 专著（M）
```
[序号] 主要责任者. 题名[M]. 出版地: 出版社, 出版年: 起页-止页.
```
例：`[2] 陈洪章. 生物质化工工程[M]. 北京: 化学工业出版社, 2018: 85-92.`

### 标准（S）
```
[序号] 标准编号, 标准名称[S]. 出版地: 出版社, 出版年.
```
例：`[3] GB/T 7829-2015, 故障树分析[S]. 北京: 中国标准出版社, 2015.`

### 专利（P）
```
[序号] 专利申请人. 专利名称: 专利号[P]. 公开日期.
```
例：`[4] 万华化学集团. 一种制备环氧丙烷的方法: CN112174765B[P]. 2022-03-15.`

### 会议论文（C）
```
[序号] 主要责任者. 题名[C]//会议名. 出版地: 出版社, 出版年: 起页-止页.
```

### 学位论文（D）
```
[序号] 主要责任者. 题名[D]. 保存地: 保存单位, 年份.
```

### 电子文献/网页（OL）
```
[序号] 主要责任者. 题名[EB/OL]. 网址, 发布日期[引用日期].
```

## 四、引用质量准则

1. 优先 5 年内的权威综述与高被引论文。
2. 标准与规范必须用最新现行版本。
3. 同一观点不堆叠 3 篇以上引用。
4. 不得引用维基百科、知乎、未署名 PPT 等作为权威来源。
5. 网络数据须标注查询日期，且必须有官方/权威背书。
