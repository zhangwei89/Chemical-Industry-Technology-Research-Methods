# 第 2 章 技术问题识别 —— 细纲

> **本章核心问题**：研发课题选错了，再多投入也是浪费。一线工程师如何从企业的海量痛点中筛出真正值得立项的真问题？
> **学习目标**：
> 1. 能区分"真问题"、"伪问题"、"战略问题"三类。
> 2. 能从七大来源（工艺/产品/安全/装备/能耗/环保/外部）系统梳理出至少 30 个待解决问题。
> 3. 能用结构化问题清单（八列模板）描述一个具体问题。

## 节级细纲

### 2.1 企业真正需要解决的问题（约 1000 字）

**核心问题**：为什么 CEO 提的"搞一个新材料"经常不是真问题？真问题和伪问题的边界在哪里？

**方法与工具**：
- "真问题三要素"：边界清晰、可量化、能验证。
- "伪问题四类识别"：目标模糊、口号式、范围过大、不可证伪。
- 给出 5WHY / 5W1H 在问题定义阶段的应用方法。

**典型化案例**：
- 案例 2-1：某企业"提高装置产能 10%"的口号式目标，被改写为"在不增加反应釜的前提下，通过提升反应速率常数 k，使停留时间从 4h 缩短到 3h，年产能提升 8%"。

**常见坑**：
- 把"领导说的"当作"必须做的"。
- 用形容词定义目标（"显著""明显""大幅"）。

### 2.2 工艺问题来源（约 900 字）

**核心问题**：反应、分离、传热、精制等工艺环节的问题各有什么典型表现？

**方法与工具**：
- 六大工艺单元的反应型问题分类：反应 / 分离 / 传热 / 精制 / 输送 / 控制。
- 每类给出 2-3 个典型症状。

**典型化案例**：
- 案例 2-2：某 PTA 装置氧化反应器结垢导致停车频率升高。

**常见坑**：
- 把工艺问题归结为"操作不稳"，忽略本质机理。

### 2.3 产品问题来源（约 800 字）

**核心问题**：客户投诉的"产品质量"问题怎么拆解成可研发的子问题？

**方法与工具**：
- 产品性能四象限：纯度 / 性能 / 稳定性 / 加工性。
- 客户需求 → 性能指标 → 工艺参数的转化链条。

**典型化案例**：
- 案例 2-3：某改性塑料用户投诉"韧性不足"，拆解为分子量分布、共聚单体比例、增韧剂分散度三个子问题。

**常见坑**：
- 把"客户要便宜"当产品问题（实为商务问题）。
- 性能指标和工艺参数不对应。

---

### 2.4 安全问题来源（约 900 字）

**核心问题**：安全问题的源头识别为什么不能依赖"经验感觉"？有什么系统化方法？

**方法与工具**：
- 事故因果链：根本原因 → 触发条件 → 事故后果。
- HAZOP / JSA / Bow-Tie 三种工具的适用场景（先埋钩子，本书第 13 章详解）。

**典型化案例**：
- 案例 2-4：2019 年某化工企业反应釜超压事故的因果链还原。

**常见坑**：
- 把事故原因归为"违章操作"，未追溯工艺本质。
- 重视事故触发条件，忽视根本原因。

### 2.5 装备问题来源（约 700 字）

**核心问题**：装备问题为什么常常被误归类为工艺问题？怎么识别"卡设备"而不是"卡工艺"？

**方法与工具**：
- 装备问题四象限：结构 / 材料 / 控制 / 维护。
- 装备失效模式（FMEA）初步介绍。

**典型化案例**：
- 案例 2-5：某换热器列管腐蚀导致传热系数下降，被误判为"循环水水质问题"。

**常见坑**：
- 一遇到产能问题就换设备，忽略工艺优化空间。
- 装备改造决策未做经济性评估。

---

### 2.6 能耗问题来源（约 700 字）

**核心问题**：能耗问题的识别为什么必须先做能量平衡？有哪些常用工具？

**方法与工具**：
- 夹点分析（Pinch Analysis）的入门概念（本书第 11 章深入）。
- 单位产品综合能耗 vs 单项能耗指标的辨析。

**典型化案例**：
- 案例 2-6：某乙烯装置通过夹点分析优化换热网络，年节能量 2.8 万吨标煤。

**常见坑**：
- 只看总能耗，不看单位产品能耗。
- 节能改造只盯"大设备"，忽略"小漏点"。

---

### 2.7 环保问题来源（约 700 字）

**核心问题**：环保问题怎么提前识别而不是等到了排放超标才补救？

**方法与工具**：
- 三废（废水 / 废气 / 废固）的源头识别。
- VOC、特征污染物、碳排放三类指标的差异化处理。

**典型化案例**：
- 案例 2-7：某农药厂废水 COD 不达标，倒推发现反应原料转化率仅 70%。

**常见坑**：
- 把环保问题归到"末端治理"，忽略源头削减。
- 用单一指标（达标 / 不达标）判断环保风险。

---

### 2.8 建立问题清单（约 1100 字）

**核心问题**：识别了一堆问题，怎么排序、怎么立项、怎么追踪？

**方法与工具**：
- 八列问题清单模板：编号 / 问题描述 / 来源 / 严重度 / 紧急度 / 涉及范围 / 责任人 / 状态。
- 严重度×紧急度矩阵（艾森豪威尔矩阵的工程化版）。
- 与企业战略对齐的方法。

**典型化案例**：
- 案例 2-8：某研究院用问题清单+月度评审机制，把 60+ 项待解决课题压缩到 12 项重点课题。

**常见坑**：
- 问题清单变"留言板"，无人跟进。
- 严重度评分主观化，缺少统一标准。
