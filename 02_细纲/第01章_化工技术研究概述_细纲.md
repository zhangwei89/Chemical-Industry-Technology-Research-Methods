# 第 1 章 化工技术研究概述 —— 细纲

> **本章核心问题**：化工技术研究到底是一项什么样的工作，它和实验室基础研究、纯工程项目之间到底有什么不同？一线工程师应该如何理解自己的工作定位？
> **学习目标**：
> 1. 能用 5 个特征描述化工技术研究与纯科学的差异。
> 2. 能画出工程研发七大阶段闭环流程并定位自己当前所在阶段。
> 3. 能用 TRL 评估任意一项技术的成熟度。
> 4. 能识别所在企业的研发组织模式并判断其优劣。

## 节级细纲

### 1.1 化工行业技术创新特点（约 1100 字）

**核心问题**：化工技术创新为什么不能像互联网那样靠"先做了再说"？为什么必须长周期、重资产、强工程？

**方法与工具**：
- "五大特征"框架：长周期性、高投入性、强工程性、高风险性、强约束性。
- 用煤制烯烃、电池电解液、电子级特气三个典型行业事实说明。
- 引用国家科技重大专项、上市公司年报等公开数据。

**典型化案例**：
- 案例 1-1：巴斯夫 / 万华 PO-SM 一体化技术的 10+ 年开发周期。

**常见坑**：
- 把"研发"等同于"实验"，忽略中试与工业放大。
- 用互联网"快速迭代"思维对待连续化工过程。

### 1.2 技术研究与科学研究的区别（约 1300 字）

**核心问题**：同样是"研究"，为什么博士论文式的机理探索和企业的工艺开发是两套不同的游戏？

**方法与工具**：
- 六维对比表：目的 / 时间尺度 / 评价标准 / 产出形式 / 不确定性来源 / 失败成本。
- 给出"哪种问题归哪类研究"的判断准则。
- 强调两者关系：科学为技术提供可能性，技术为科学提出真问题。

**典型化案例**：
- 案例 1-2：催化剂表面反应的机理研究（科学）vs 该催化剂的工业成型与放大（技术）。

**常见坑**：
- 用 SCI 论文标准评价工程研发产出。
- 用工程指标要求博士课题。

### 1.3 工程研发流程（约 1400 字）

**核心问题**：从"实验室有新发现"到"工厂稳定生产出合格产品"，中间要经历哪几步？每步的"通过条件"是什么？

**方法与工具**：
- 七阶段闭环：小试 → 工艺包 → 中试 → 工程设计 → 建设 → 试车 → 工业化运营 → 反馈。
- 每阶段给出输入、输出、通过条件（Go/No-Go gate）。
- 强调"阶段门"（Stage Gate）决策机制。

**典型化案例**：
- 案例 1-3：某新型聚烯烃催化剂从公斤级小试到 30 万吨/年工业装置的 8 年路径。

**常见坑**：
- 跳过中试直接放大，遗留放大效应。
- 在试车阶段才发现工艺包的根本性错误。

### 1.4 化工研发组织模式（约 1200 字）

**核心问题**：大企业的研发部、研究院、生产车间应该如何分工？小公司没有专门研究院怎么办？

**方法与工具**：
- 三种典型模式：集中式研究院、分布式研发、矩阵式协同。
- 每种模式给一个代表企业（巴斯夫 / 陶氏 / 中石化）。
- 给出"企业规模 vs 研发组织"的匹配表。

**典型化案例**：
- 案例 1-4：万华化学的"研究院 + 事业部技术部"双层架构。

**常见坑**：
- 研究院与生产部脱节，成果难以转化。
- 矩阵管理下，研发人员多头汇报。

### 1.5 技术成熟度（TRL）评价（约 1100 字）

**核心问题**：我手里的这项技术到底能不能上工业线？有没有一个相对客观的尺子？

**方法与工具**：
- TRL 1-9 九级定义（NASA / EU / 国标 GB/T 38751 互相对照）。
- 每级给出"通过条件"和典型产出。
- 给出 TRL 自评 check list。

**典型化案例**：
- 案例 1-5：某新型吸收剂从 TRL 3 到 TRL 7 的逐级跨越。

**常见坑**：
- 把"实验室反复做出结果"等同于 TRL 4-5。
- 用 TRL 自我安慰（实际只到 3，自评为 6）。

### 1.6 化工研发的发展趋势（约 1100 字）

**核心问题**：未来 5-10 年，化工研发会被哪些力量重塑？一线工程师如何不掉队？

**方法与工具**：
- 六大趋势：① 数字化与 AI 赋能；② 绿色低碳与碳中和；③ 过程强化与连续流；④ 高端材料国产替代；⑤ 跨学科协同；⑥ 知识产权与标准化竞争。
- 每个趋势给一个公开事实作为佐证。

**典型化案例**：
- 案例 1-6：某国内电池材料企业用 AI 辅助电解液配方筛选的公开报道。

**常见坑**：
- 把"AI for chemistry"等同于"未来一定会替代研发人员"。
- 盲目追热点，忽略本职专业深度。
