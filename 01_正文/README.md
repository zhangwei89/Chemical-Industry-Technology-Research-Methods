# 化工行业技术研究方法

> 从科研选题到工业化应用 — 一线研发工程师的系统教材

## 关于本书

本书面向化工企业一线研发工程师（25-40 岁，本科/硕士为主），系统覆盖化工研发的完整链条：

- **第一篇** 化工技术研究基础（3 章）
- **第二篇** 技术研究设计（4 章）
- **第三篇** 数据研究方法（3 章）
- **第四篇** 化工研发核心方法（4 章）
- **第五篇** 中试放大研究（3 章）
- **第六篇** 技术创新方法（3 章）
- **第七篇** 技术成果形成（3 章）
- **第八篇** 数字化研发（3 章）
- **第九篇** 典型案例（4 章）

**共 30 章正文 + 前言 + 10 附录，约 20.8 万字。**

## 内容特色

1. **工程化语言**：用一线工程师听得懂的话讲方法论，不搞学术八股。
2. **结构化方法**：每个方法都有"做什么 / 怎么做 / 用什么工具 / 常见坑"四段式结构。
3. **典型化案例**：所有案例均基于公开行业资料构造化呈现，避免不可查证的细节。
4. **可复用的模板**：附录提供 DOE、HAZOP、技术路线、可研报告等 10 类标准化模板。
5. **覆盖完整链条**：从科研选题到工业化应用，每个环节都有对应章节。

## 阅读建议

- **新手工程师**（3 个月）：按章节顺序读，重点放在前 17 章。
- **资深工程师**（按需查阅）：直接看相关章节的"常见坑"和方法与工具。
- **研发管理者**（1 个月）：重点看 18-26 章（创新、专利、报告、数字化）。
