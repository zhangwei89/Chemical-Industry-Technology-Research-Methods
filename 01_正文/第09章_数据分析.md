# 第 9 章 数据分析

> **本章核心问题**：数据有了，怎么从数据里提取出能指导研发决策的信息？
>
> **学习目标**：
> 1. 能用七类基础分析方法（清洗/统计/回归/方差/SPC/趋势/相关）处理一套化工数据。
> 2. 能针对具体问题选择合适的方法组合。
> 3. 能用开源工具（Python / R）做一次完整的化工数据分析任务。

## 开篇引子

某研究院的研发主管每次看数据报告都说「感觉不对」但又说不出哪里不对。分析员小高尝试了 5 种分析工具，最后用一张时序图 + 关键变量趋势对比，找到了问题：催化剂活性从第 30 天开始出现微小的线性下降，速率约 0.5%/天。这种信号在单机分析的报表里完全看不出来，但在时序趋势图上一目了然。小高这才意识到，数据分析的难处不在算法，而在「用什么视角看数据」。

数据分析是化工研发的「放大镜」和「望远镜」：放大镜帮你看清细节，望远镜帮你看清趋势。本章任务，是给一线工程师一套常用数据分析方法的工具箱：数据清洗、统计描述、回归分析、方差分析、SPC、趋势分析、相关性分析，每一类都给出方法原理 + 化工应用场景 + 工具实现路径。

## 9.1 数据清洗

### 核心问题

数据清洗应该包含哪些动作？为什么不洗干净就别做分析？

### 方法与工具

**数据清洗的八大动作**：

| 动作 | 内容 | 典型处理 |
|---|---|---|
| **去重** | 重复记录识别与删除 | 按时间戳和变量名组合 |
| **缺失值处理** | 删除 / 插值 / 模型填补 | 缺失率 < 5% 删除，5%-20% 插值 |
| **异常值处理** | 离群点识别与处理 | 3σ 准则、IQR 准则 |
| **单位统一** | 不一致单位的换算 | °C/K、bar/MPa/Pa |
| **时间对齐** | 不同子系统时钟统一 | UTC 化 + 偏差校正 |
| **坐标系转换** | 局部坐标 → 全局坐标 | 经纬度、坐标系 |
| **数据类型转换** | 字符串 → 数值 / 日期 | 解析失败标 NA |
| **元数据补全** | 缺少的元数据补充 | 设备名、批次号、操作员 |

**缺失值的三种处理策略**：

- **删除**：缺失比例低（< 5%）且非随机缺失时适用。
- **插值**：时间相邻点缺失用线性/样条插值；用前向填充/后向填充。
- **模型填补**：多变量关系明显时用 KNN、随机森林等做模型填补。

### 常见坑

1. **机械删除缺失值**：可能引入偏差，应先判断缺失机制（随机/非随机）。
2. **异常值直接删除**：先查是否真实异常还是传感器故障，故障数据应标记而非删除。

## 9.2 描述性统计

### 核心问题

描述性统计应该给出哪些量？怎么看分布形态？

### 方法与工具

**基础统计量**：

- **中心趋势**：均值（Mean）、中位数（Median）、众数（Mode）。
- **离散程度**：标准差（SD）、方差（Var）、四分位距（IQR）、极差（Range）、变异系数（CV = SD/Mean）。
- **分布形态**：偏度（Skewness，反映左右不对称）、峰度（Kurtosis，反映尖平度）。

**常用可视化**：

- 直方图（Histogram）：看分布形状。
- 箱线图（Box Plot）：看分布与离群点。
- Q-Q 图：检查正态性。

### 常见坑

1. **只用均值描述数据**：忽视方差和分布形态，极易误判。
2. **不检查分布形态**：直接套用正态分布假设的统计方法，可能出错。

## 9.3 回归分析

### 核心问题

回归分析在化工中怎么用？怎么选择合适的回归模型？

### 方法与工具

**回归分析的常见任务**：

- **建立过程 - 质量关系**：识别关键过程变量。
- **建立变量间因果**：定量分析工艺条件如何影响产品质量。
- **预测新条件结果**：在工艺窗口内预测。

**常用回归模型对比**：

| 模型 | 优势 | 劣势 | 适用场景 |
|---|---|---|---|
| **线性回归（OLS）** | 简单、可解释 | 仅线性 | 关系明显线性 |
| **偏最小二乘（PLS）** | 处理高维共线性 | 黑盒 | 光谱、NIR |
| **多项式回归** | 拟合曲线 | 易过拟合 | 已知非线性 |
| **决策树** | 非参数、易解释 | 易过拟合、不平滑 | 分段函数 |
| **随机森林 / XGBoost** | 高精度、自动特征选择 | 黑盒、需调参 | 高维复杂 |
| **高斯过程回归** | 可给出预测不确定性 | 计算成本高 | 样本少需置信度 |

### 典型化案例

**典型化案例 9-1**（行业公开资料）

- **背景**：某反应器转化率建模，有 30 个潜在工艺变量。
- **问题**：变量过多，线性回归模型过拟合且解释性差。
- **解法**：先用 PLS 降至 5 个主成分，再用 XGBoost 做精细建模；用 SHAP 值解释变量重要性。
- **结果**：建模 R² = 0.92，泛化误差 2%；识别出三个最关键变量。
- **启示**：变量过多时，「降维 + 黑盒」是常见组合。

### 常见坑

1. **训练集和测试集划分不当**：用未来预测过去（时序数据不允许随机划分）。
2. **不验证模型假设**：OLS 假定残差正态、独立、等方差，应做残差分析。

## 9.4 方差分析（ANOVA）

### 核心问题

方差分析在化工中怎么用？单因素和多因素方差分析的边界是什么？

### 方法与工具

**单因素 ANOVA**：比较一个分类变量不同水平下连续响应是否有显著差异。例如：3 个供应商原料的产品杂质均值是否有差异。

**多因素 ANOVA（含交互）**：研究多个分类变量及其交互对响应的影响。例如：温度（A 因子）× 压力（B 因子）对收率的影响。

**方差分析的输出**：

- F 统计量与对应 p 值：p < 0.05 视为显著。
- 效应量（η²）：量化因子解释的方差比例。
- 多重比较（Tukey HSD）：识别显著差异的具体水平对。

### 常见坑

1. **多重比较不修正**：多次比较会增加 I 型错误，建议用 Bonferroni 或 Tukey 校正。
2. **小样本硬上 ANOVA**：每组样本 < 5 个时，ANOVA 检验力不足。

## 9.5 SPC 统计过程控制

### 核心问题

SPC 怎么从「事后分析」走向「实时预警」？

### 方法与工具

**控制图（Control Chart）五大类型**：

| 图 | 用途 | 控制限 |
|---|---|---|
| **I-MR** | 单点连续数据 | 个体值 ± 3σ |
| **Xbar-R** | 子组均值与极差 | 均值 ± A2·Rbar |
| **P-Chart** | 不合格品率 | p ± 3·√(p(1-p)/n) |
| **NP-Chart** | 不合格品数 | np ± 3·√(np(1-p)) |
| **CUSUM / EWMA** | 漂移检测 | K=0.5σ |

**SPC 实施五步法**：

1. **选择控制变量**：质量、过程参数或稳定性指标。
2. **采集基线数据**：≥ 25 个子组识别稳态。
3. **计算控制限**：避免使用过程中的数据。
4. **运行监控**：超出控制限立即报警。
5. **更新控制限**：工艺变更、设备更换、季节变化后需重算。

**CUSUM 在化工中的应用**：对催化剂失活速率（缓慢漂移信号）特别有效，可在失活发生几周甚至几个月前预警。

### 常见坑

1. **控制限过紧**：把正常波动当作异常报警，导致频繁误报。
2. **忽视控制限维护**：工艺变更后未重算限值，导致漏报。

## 9.6 趋势与相关性分析

### 核心问题

趋势分析与 SPC 有什么区别？相关性分析在化工中怎么用？

### 方法与工具

**趋势分析**：识别变量随时间的长期方向（递增/递减）、周期性、季节性、突变。常用方法：

- **移动平均（MA）**：平滑短期波动看长期趋势。
- **指数平滑（ES）**：加权近期数据。
- **STL 分解**：把时间序列分解为趋势、季节、残差。
- **变点检测**：识别突变点（如催化剂寿命拐点）。

**相关性分析**：

- **Pearson 相关系数**：线性相关。
- **Spearman 等级相关**：单调非线性相关。
- **互信息（MI）**：捕捉任意关系。
- **时滞相关**：识别变量的时滞关系（如进料波动 1h 后出料响应）。
- **偏相关**：控制其他变量后两个变量的纯相关。

**化工典型场景**：

- 进料组成与产品质量的时滞相关。
- 设备振动与产品质量的关联。
- 季节性原水水质对工艺的影响。

### 常见坑

1. **相关 ≠ 因果**：高相关可能因为二者都受第三个变量影响。
2. **忽视时滞**：直接做同时刻相关可能错过最佳关联时刻。

## 9.7 敏感性分析

### 核心问题

敏感性分析在工艺优化中怎么用？

### 方法与工具

**两类敏感性分析**：

1. **局部敏感性**：每次改变一个变量，看响应变化（One-At-a-Time, OAT）。
2. **全局敏感性**：考虑变量间交互，常用方法有 Sobol 指数、Morris 筛选、FAST。

**化工典型应用**：

- 工艺参数优化的关键变量识别。
- 公差设计：哪些变量波动对最终结果影响最大。
- 蒙特卡洛模拟：把关键变量作为概率分布输入，预测结果分布。

### 常见坑

1. **OAT 代替全局**：忽视交互效应可能错过关键变量。
2. **无视分布假设**：把变量当正态分布假设可能与实际不符。

## 本章小结

回到本章开篇的「主管说感觉不对」困局，可以用本章的几个核心判断来回应：

1. **数据分析是放大镜 + 望远镜**：放大镜（描述统计 + SPC）看细节，望远镜（趋势 + 回归）看长期。
2. **数据清洗是必过关**：不正确的数据会误导任何模型。
3. **回归分析首选线性 / PLS**：解释性强；只有关系复杂时才用 XGBoost 等黑盒。
4. **方差分析解决「分组对比」**：原料供应商、班组、设备间差异的标准化方法。
5. **SPC 是质量稳定的实时哨兵**：从 I-MR 到 CUSUM，按信号特征选择。
6. **趋势与相关**：移动平均看趋势，偏相关看真实关联。
7. **敏感性分析**：OAT 入门，全局方法严谨化。

第 10 章开始，我们沿着研发地图的第八节点——「建模与模拟」——深入，把数据分析升级为预测与优化。

1. 用一组真实的化工数据（含缺失值、异常值、单位混乱），写一套完整的数据清洗脚本（Python）。
2. 对一个 3 因子 3 水平的实验数据，做方差分析（ANOVA）与多重比较（Tukey），输出因子重要性。
3. 对一组连续工艺数据，建立 I-MR 控制图，识别越限点与趋势性变化。
4. 对一组过程与质量关联数据，建立 PLS 与 XGBoost 两个模型，对比精度与可解释性。
5. 用公开数据集（如 UCI 化工数据集）做端到端的化工数据分析项目（含清洗、描述、建模、验证、报告）。
