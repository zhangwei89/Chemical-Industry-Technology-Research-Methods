## 写作约束

- **目标读者**：化工企业一线研发工程师（25-40 岁，本科/硕士为主）。
- **风格基线**：高级工程师/项目经理口吻，平视读者。不用"我"作主语。
- **章节结构**：开篇引子 → 6-8 节（核心问题/方法与工具/典型化案例/常见坑）→ 本章小结 → 思考题 → 参考文献。
- **图表**：以 mermaid 为主（流程图、矩阵图、甘特图、决策树），编号格式 `图 X-Y` / `表 X-Y`。
- **案例**：标注「典型化案例 X-Y（出处类型）」，构造化而非虚构具体公司/专利。
- **参考文献**：标准类、工具书类引用真实权威来源；期刊类为示意占位，文末注明确说明。
