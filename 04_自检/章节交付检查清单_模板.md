# 章节交付检查清单

> 每章正文交付前，作者必须自检并填写本表。

## 一、基础项

| 检查项 | 阈值 | 实际 | 通过 |
|---|---|---|---|
| 章节字数（中文字符） | 7000-9000 | ___ | ☐ |
| 节数 | 6-8 节 | ___ | ☐ |
| 开篇引子 | 150-300 字 | ___ | ☐ |
| 本章小结 | 300-500 字 | ___ | ☐ |
| 思考题 | 3-5 题 | ___ | ☐ |
| 参考文献 | 5-15 条 | ___ | ☐ |
| 配图（含表） | ≥ 6 张 | ___ | ☐ |

## 二、术语一致性（对照 02_术语表.md）

- [ ] 本章新出现的术语已追加进术语表
- [ ] 全章同一概念用同一术语，无"研发 / 研究 / 调研"混用
- [ ] 缩写首次出现给中英文全称
- [ ] 未自造缩写（除行业公认外）

## 三、逻辑闭环

- [ ] 开篇核心问题在前 3 节有明确回应
- [ ] 每节"核心问题 → 方法 → 工具 → 案例 → 常见坑"五件套完整
- [ ] 各节之间有过渡，不孤立
- [ ] 本章小结 5-8 条要点回扣开篇
- [ ] 思考题与正文方法论挂钩，可练习

## 四、引用规范

- [ ] 文内引用全部能在文末参考文献中找到
- [ ] 文末条目格式符合 GB/T 7714
- [ ] 无"维基百科 / 知乎 / 内部 PPT"等不可溯源引用
- [ ] 标准/规范使用最新现行版本
- [ ] 同一观点不堆叠 3 篇以上引用

## 五、案例与图表

- [ ] 每节至少 1 个典型化案例或工具/方法示意
- [ ] 案例标注"典型化案例 X-Y"并写出处类型
- [ ] 图编号格式 `图 X-Y` 正确，图下有图题与解读
- [ ] 表编号格式 `表 X-Y` 正确
- [ ] 无凭空编造公司名、专利号、产品牌号

## 六、风格与表达

- [ ] 无空话（"未来可期""值得期待""不言而喻"）
- [ ] 无网络梗、口语化过度
- [ ] 关键论断尽量量化（数字 / 比例 / 区间）
- [ ] 不以"我"作主语
- [ ] 无 emoji（除 [x] 等目录标记）
- [ ] 中英文标点统一（中文段落用全角，代码/英文术语用半角）
