# 化工行业技术研究方法

> 与 [Action-System](https://zhangwei89.github.io/Action-System/) 共用红色主题 `#c0392b`。

## 这是什么

面向**化工方向技术人员**的研究方法手册——立项前信息收集、技术路线对比、报告撰写、风险呈现。结构遵循「目的 → 方法 → 数据 → 判断 → 表达」五段法。

## 章节目录

| # | 章节 | 状态 |
|---|---|---|
| 第一章 | 立项：明确问题与边界 | 占位 |
| 第二章 | 信息源：分类、可信度、覆盖度 | 占位 |
| 第三章 | 技术路线对比：参数矩阵与决策表 | 占位 |
| 第四章 | 数据采集：实验、台账、文献 | 占位 |
| 第五章 | 数据处理：清洗、不确定性、缺失值 | 占位 |
| 第六章 | 可行性判断：实验室 → 中试 → 工业化 | 占位 |
| 第七章 | 报告结构：背景、方法、结果、风险 | 占位 |
| 第八章 | 演示：图表、模板、答辩 | 占位 |

## 本地构建

```bash
pip install mkdocs==1.6.1 mkdocs-material==9.7.6 pymdown-extensions==11.0.1
mkdocs serve                 # 本地预览
mkdocs gh-deploy --force     # 推到 gh-pages 分支
```

## 协作约定

- 主分支：`main`
- 内容源：`docs/`（MkDocs）
- 部署：GitHub Actions，自动推到 Pages
- 内容校对：在 PR 上互看，至少两位化工背景人员 sign-off

!!! note "本页只是占位"
    真正的章节内容会随后补充。本页存在的原因：让 `mkdocs build --strict` 通过校验，确保主题色与 Action-System 保持一致。
